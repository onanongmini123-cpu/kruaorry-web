## ทุกบัญชี
- [ ] 1. หน้าแรก: เห็นแถว ❤️ ครูกดหัวใจมากที่สุด / 🔥 ยอดนิยม / 🆕 ใหม่ล่าสุด เลื่อนด้วยนิ้วได้ ไม่ล้นจอ แถวที่มีไม่ถึง 3 รายการต้องไม่แสดง
- [ ] 2. carousel "ครูอรรี่เลือกมาให้แล้ว" ยังอยู่เหมือนเดิม
- [ ] 3. การ์ดสื่อ Pro ที่มีภาพตัวอย่างมีป้าย "ทดลองได้" สื่อฟรีไม่มีป้ายนี้
- [ ] 4. หน้า `/resources` และหน้ารายละเอียดสื่อเปิดได้ ❤️ ที่เคยกดไว้ยังอยู่ครบ

## ไม่ล็อกอิน และสมาชิกฟรี
- [ ] 5. หน้าสื่อ Pro: เห็นหัวข้อ "ทดลองดูตัวอย่าง" รูปมีลายน้ำ "KruAorry.com – ตัวอย่าง" ทั่วทั้งภาพ
- [ ] 6. ปุ่ม "อยากใช้ฉบับเต็ม? สมัคร Teacher Pro" ไปหน้า `/membership`
- [ ] 7. ปุ่มหลักของสื่อ Pro ไป `/membership` ไม่เปิดไฟล์หรือเกมจริง
- [ ] 8. ลองเปิดที่อยู่ `/api/resources/<รหัสสื่อ>/open` ในแท็บใหม่ต้องขึ้นว่าไม่มีสิทธิ์ ไม่เด้งไปที่เกมหรือไฟล์จริง
- [ ] 9. หน้าสื่อที่มีวิดีโอ: เห็นภาพตัวอย่างก่อน กดแล้วจึงเล่น วิดีโอเล่นได้

## Teacher Pro และ Founder
- [ ] 10. สื่อ Pro เปิดหรือดาวน์โหลดได้ตามปกติ ไม่มีลายน้ำ ไม่มีหัวข้อ "ทดลองดูตัวอย่าง"

## แอดมิน
- [ ] 11. ในหน้า "จัดการสื่อ": ตั้งวิดีโอหน้าแรกได้ (1–3 รายการ) เพิ่มลิงก์วิดีโอวิธีเล่นในสื่อได้
- [ ] 12. เพิ่มรูปตัวอย่างในสื่อ Pro: เห็นลายน้ำในรูปที่ได้ และกด "บันทึกรูปตัวอย่าง" แล้วรูปขึ้นบนหน้าสื่อ
- [ ] 13. เปิดหน้าสื่อด้วยบัญชีแอดมินหลายครั้ง แล้วดูว่าอันดับ 🔥 ไม่เพิ่ม (แอดมินไม่ถูกนับ)
