# Runbook: ตั้ง slug ให้สื่อใหม่

เอกสารนี้ใช้เมื่อเพิ่มสื่อใหม่แล้วต้องการ URL ที่อ่านง่าย เช่น
`https://kruaorry.com/resources/my-classroom-game`

ปัจจุบันหน้าแอดมินยังไม่มีช่อง slug ดังนั้นสื่อใหม่จะใช้ URL แบบ UUID
จนกว่าเจ้าของระบบจะตั้ง slug ด้วย SQL ตามขั้นตอนนี้

## 1. ตรวจรายการที่ยังไม่มี slug

รันคำสั่งแบบอ่านอย่างเดียวใน Supabase SQL Editor:

```sql
select id, title
from public.resources
where status = 'published'
  and slug is null
order by title;
```

ตรวจชื่อและ `id` ของรายการเป้าหมายให้ตรงก่อนดำเนินการต่อ

## 2. เลือก slug

slug ต้องเป็นไปตามกติกาต่อไปนี้:

- ใช้ตัวพิมพ์เล็กภาษาอังกฤษ (`a-z`) และตัวเลข (`0-9`)
- คั่นคำด้วยขีดกลาง (`-`)
- ยาว 3–80 ตัวอักษร
- ห้ามซ้ำกับสื่ออื่น
- ห้ามมีช่องว่าง ตัวพิมพ์ใหญ่ หรืออักขระภาษาไทย

ตัวอย่างที่ถูกต้อง: `my-classroom-game`, `phonics-level-2`

ฐานข้อมูลมี constraint ตรวจรูปแบบและความซ้ำ หากค่าไม่ถูกต้องคำสั่งจะถูกปฏิเสธ

## 3. ตั้งค่าโดยไม่เขียนทับ slug เดิม

แทน `<slug>` และ `<uuid>` ด้วยค่าของรายการเป้าหมาย แล้วให้เจ้าของระบบรันใน
Supabase SQL Editor:

```sql
update public.resources
set slug = '<slug>'
where id = '<uuid>'
  and slug is null;
```

เงื่อนไข `slug is null` ป้องกันไม่ให้คำสั่งนี้เขียนทับ slug ที่มีอยู่แล้ว

## 4. ตรวจผล

1. รอราว 5–6 นาทีให้แคชข้อมูลหมดอายุ
2. เปิดหน้ารายการสื่อสองครั้ง โดยคำขอแรกหลังหมดอายุอาจยังได้ข้อมูลเดิมและเป็นผู้สั่ง refresh
3. เปิด `https://kruaorry.com/resources/<slug>` และตรวจว่าหน้าสื่อตรงกับรายการที่ตั้ง
4. เปิด `https://kruaorry.com/sitemap.xml` และตรวจว่ามี URL แบบ slug ของรายการนั้น

หากคำสั่ง `update` ไม่เปลี่ยนแถวใด ให้หยุดและตรวจ `id` กับสถานะ slug ปัจจุบัน
ห้ามตัดเงื่อนไข `slug is null` ออกเพื่อบังคับเขียนทับ
