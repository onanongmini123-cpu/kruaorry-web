# นักสืบไขคดี (Detective Mystery) — เกมการศึกษา 2D สำหรับห้องเรียน

เกมไขคดีแบบไม่รุนแรง (ของหาย/ของสลับ/ป้ายหาย) ครูเป็น Game Master เล่นบนคอมเครื่องเดียวต่อจอทีวี/โปรเจกเตอร์ นักเรียนไม่ต้องมีโทรศัพท์
เป็นไฟล์ Static ล้วน: `index.html` ไฟล์เดียว (HTML + CSS + JS ฝังในไฟล์) ไม่เรียก CDN / ฟอนต์ภายนอก / API / ตัวติดตาม / iframe

## ไฟล์ในโฟลเดอร์

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` | ตัวเกมทั้งหมด (จุดเริ่มต้น) |
| `sample-questions.json` | คดีตัวอย่าง "ถ้วยรางวัลหายจากห้องสมุด" (8 หลักฐาน 8 คำถาม) รูปแบบ `schemaVersion: 1` นำเข้าได้ เล่นจบได้ |
| `README.md` | ไฟล์นี้ |

## วิธีเปิดและเล่น

1. เปิด `index.html` ด้วย Chrome / Edge / Firefox / Safari (ทำงานได้ทั้งเปิดจากไฟล์ หรืออัปโหลดขึ้นเว็บ Static)
2. หน้าแรกมี: **เริ่มเล่น**, **เล่นต่อ** (ถ้ามีเกมที่บันทึกไว้), **จัดการเนื้อหา**, **ตั้งค่า**, **วิธีเล่น**, **ทดลองเล่น**
3. **เริ่มเล่น** → เลือกคดี/โหมด → ระบบตรวจข้อมูลคดีก่อน (ถ้ามีจุดผิดจะไม่ให้เริ่ม และบอกว่าต้องแก้อะไร)
4. ในเกม (วนซ้ำจนไขคดีได้):
   - **สืบสวน**: เดินในแผนที่ 4 ห้อง (คลิกที่แผนที่ / ลูกศร หรือ WASD / ปุ่มรายการ "จุดสืบสวน") ใช้แว่นขยายที่ตามเมาส์ส่องหาจุด ตอบคำถามของครูถูกจึงเปิดหลักฐาน (ฉากเผยหลักฐาน)
   - **เชื่อมหลักฐาน**: บนกระดานหลักฐาน (โพสต์อิต + เส้นโยงสีชัด) คลิกโน้ต 2 อัน (หลักฐาน/เวลา/บุคคล) แล้วเขียนคำอธิบาย ลากโน้ตเพื่อจัดวางได้
   - **สรุปคดี**: เลือกข้อสรุป + หลักฐานที่ใช้ยืนยัน + เหตุผล ถ้ายังไม่พอจะขึ้น "ยังมีหลักฐานไม่เพียงพอ" และลองใหม่ได้ไม่จำกัดครั้ง
   - ครูกด **จบ/รายงาน** → รายงานสั้น (สิ่งที่เกิดขึ้น, หลักฐานหลัก, เหตุผล) → ครูกด **เปิดเฉลยทีละขั้น**
5. ปุ่มลัด: `ลูกศร/WASD` เดิน, `Enter` ยืนยัน/สืบสวนจุดที่ยืนใกล้, `Space` พัก/เล่นต่อ, `Esc` ปิดหน้าต่าง

### โหมดการเล่น
- **แข่งขันเป็นทีม 2–8 ทีม**: ผลัดกันตอบทีละตา (ตอบถูกหรือยังไม่ถูกก็ส่งต่อให้ทีมถัดไป จำนวนข้อใกล้เคียงกัน) ทุกทีมใช้กระดานหลักฐานร่วมกัน ผู้เสนอเส้นเชื่อม/ข้อสรุปเลือกทีมได้
- **ร่วมมือทั้งห้อง**: ทีมเดียว คะแนนรวม ไม่มีสลับตา
- **ฝึกคนเดียว**: ผู้เล่น 1 คน (ตอบผิดลองใหม่ได้ทันที)

### แผงครู (Game Master) — ปุ่ม "แผงครู" ในเกม
สลับทีม · แก้คะแนน (บวก/ลบ ระบุเหตุผล) · ย้อนคำสั่งล่าสุด (Undo) · พัก/เล่นต่อ · ปลดหลักฐาน (ไม่ให้คะแนน) · ชวนอภิปราย (สุ่มจากคำถามที่ครูตั้ง) · จบก่อนเวลา · รีสตาร์ท (ยืนยันก่อน) · เฉลยข้อที่เปิดอยู่ ("ครู: เฉลยข้อนี้") — คำเฉลยไม่แสดงบนจอจนกว่าครูกด

## คะแนนและความเป็นธรรม
ตอบถูก **+10** · เชื่อมหลักฐานสมเหตุสมผลตามคู่ที่ครูกำหนด **+10** (ต่อคู่ ครั้งเดียว) · สรุปคดีพร้อมหลักฐานหลักถูกต้อง **+20**
(ปรับค่าได้ที่ **ตั้งค่า**) ไม่มีคะแนนจากความเร็ว ไม่หักคะแนนเมื่อเดาไม่ถูก/ใช้คำใบ้/หมดเวลา ตารางที่มาคะแนน ("ที่มาคะแนน") อธิบายทุกรายการ

## ครูสร้าง/แก้คดีเอง (จัดการเนื้อหา)
เมนู **จัดการเนื้อหา** → **+ คดีใหม่** (หรือ "ทำสำเนา" คดีตัวอย่างแล้วแก้) แท็บต่าง ๆ:

1. **ข้อมูลคดี**: ชื่อคดี วิชา ระดับชั้น เรื่องราว ชื่อ 4 ห้อง
2. **ผู้เกี่ยวข้อง**: 3–5 คน (ชื่อสมมติ)
3. **หลักฐาน & คำถาม**: 5–8 ชิ้น เพิ่ม/ลบ/ทำสำเนา/เรียงลำดับ แต่ละชิ้นระบุ ห้อง เวลา ผู้เกี่ยวข้อง ลำดับเผย เบาะแสบังคับ (★) คำใบ้ รูปประกอบจากไฟล์ในเครื่อง (ย่อให้อัตโนมัติ) และ **คำถามที่ผูกหลักฐาน**: ปรนัย (2–6 ตัวเลือก แนะนำ 4) / ถูก–ผิด / คำตอบสั้น (ครูตัดสินถูก–ผิดเอง ระบบไม่เดาความหมาย) + คำอธิบาย หัวข้อ ความยาก
4. **ทางเลือก & เฉลย**: ทางเลือกสมมติฐาน 3–5 ข้อ เลือกข้อที่เป็นเฉลย ข้อความแนะนำสำหรับข้อที่ยังไม่พอ คำอธิบายเฉลย ขั้นเฉลยทีละขั้น และ "หลักฐานหลักที่ต้องอ้างอิง"
5. **เส้นเชื่อม**: คู่ (หลักฐาน/ผู้เกี่ยวข้อง/เวลา) ที่ "เชื่อมแล้วสมเหตุสมผล" พร้อมเหตุผล (ใช้ให้คะแนนเชื่อมหลักฐาน)
6. **ตั้งค่าคดี**: ความยาก (ง่าย = จุดเรืองแสง + ตัดตัวเลือก / ปานกลาง / ยาก = ซ่อนจุด ต้องใช้แว่นขยาย), บังคับลำดับเผยหลักฐาน, บังคับเบาะแสบังคับก่อนสรุป, จำนวนคำใบ้, เวลาต่อคำถาม, คำถามชวนอภิปราย
7. **ตรวจสอบ**: รายการสิ่งที่ต้องแก้ก่อนเล่น เช่น คำถามว่าง ตัวเลือกซ้ำ/ว่าง ไม่ได้เลือกคำตอบ **เฉลยหลุดในข้อความหลักฐาน/ตัวเลือก** หลักฐานหลักที่ชี้ไปคนละทางกับเฉลย ไม่มีเฉลย/หลักฐานหลัก/เส้นเชื่อม — ถ้ามีข้อผิดพลาดจะ **ไม่ให้เริ่มเล่น**

### นำเข้า / ส่งออก
- **JSON (UTF-8)** `schemaVersion: 1`: ปุ่ม "ส่งออก JSON" / "นำเข้า JSON" (เลือกไฟล์จากเครื่อง ไม่อัปโหลดที่ใด) ไฟล์นำเข้าถูกตรวจรูปแบบก่อน ข้อมูลเดิมไม่เสียหากไฟล์ผิด; ไฟล์ที่มี `schemaVersion` ใหม่กว่าจะถูกปฏิเสธ; ถ้ารหัสคดีซ้ำจะสร้างรหัสใหม่ให้
- **สำรองทั้งหมด**: ส่งออกทุกคดีเป็นไฟล์เดียว (`kind: "backup"`) นำเข้าได้ด้วยปุ่มเดิม
- **CSV (ปรนัยพื้นฐาน)**: คอลัมน์ `prompt,optionA,optionB,optionC,optionD,answer,explanation,topic,difficulty,evidence` (answer = A–D) ส่งออกแล้วป้องกัน formula injection (เซลล์ที่ขึ้นต้นด้วย `= + - @` จะถูกใส่ `'` นำหน้า) ไฟล์มี BOM เพื่อให้ Excel อ่านภาษาไทยได้ นำเข้า CSV จะสร้าง "หลักฐานร่าง" ที่ผูกกับคำถามนั้น ครูต้องเติมรายละเอียดหลักฐาน/ห้อง/เวลาก่อนเริ่มเล่น (รวมได้ไม่เกิน 8 หลักฐาน)
- ผลหลังเล่น: ส่งออก **CSV / JSON** หรือ **พิมพ์** (หน้ารายงานมี print stylesheet; เฉลยจะพิมพ์เฉพาะส่วนที่ครูเปิดแล้ว)

### รูปแบบ JSON ของคดี (ย่อ)
```json
{
  "schemaVersion": 1, "id": "...", "title": "...", "subject": "...", "grade": "...", "story": "...",
  "rooms": [{ "id": "r0", "name": "ห้องสมุด" }],
  "characters": [{ "id": "c1", "name": "...", "role": "...", "desc": "..." }],
  "evidence": [{ "id": "e1", "title": "...", "desc": "...", "room": 0, "time": "08:15", "characterIds": ["c1"],
                 "supports": "h3", "mandatory": false, "order": 1, "hint": "...", "image": "" }],
  "questions": [{ "id": "q1", "type": "single-choice", "evidenceId": "e1", "prompt": "...",
                  "options": [{ "id": "a", "text": "..." }], "answer": "a", "explanation": "...", "topic": "...", "difficulty": 1 }],
  "hypotheses": [{ "id": "h1", "text": "...", "feedback": "..." }],
  "solution": { "answer": "h3", "explanation": "...", "steps": ["..."], "keyEvidence": ["e2"] },
  "links": [{ "id": "l1", "a": "e:e2", "b": "c:c3", "reason": "..." }],
  "gameConfig": { "difficulty": 2, "enforceOrder": false, "requireMandatory": true, "hintsPerGame": 4, "questionSeconds": 0, "discussion": ["..."] }
}
```
`type`: `single-choice` (answer = id ตัวเลือก) · `true-false` (answer = `true`/`false`, `options` เป็น `[]`) · `short-answer` (answer = แนวคำตอบสำหรับครู ครูตัดสินเอง)
รหัสในเส้นเชื่อม: `e:<id หลักฐาน>` · `c:<id ผู้เกี่ยวข้อง>` · `t:<ข้อความเวลา>` (ต้องตรงกับเวลาของหลักฐานบางชิ้น)

## ตั้งค่า
หน้า **ตั้งค่า**: โหมด, จำนวนทีม 2–8 + ชื่อ/สีทีม (ค่าเริ่มต้น "ทีม 1", "ทีม 2" …), คะแนนทั้ง 3 ประเภท, เปิด/ปิดจับเวลา (เวลาต่อข้ออยู่ในตั้งค่าคดี; หมดเวลาไม่หักคะแนน ครูกด "ต่อเวลา" ได้), สลับลำดับตัวเลือก, เสียง/เพลงบรรยากาศ, ลดการเคลื่อนไหว (รองรับ `prefers-reduced-motion`), เต็มจอ, ล้างข้อมูลทั้งหมด

## การเก็บข้อมูลและการสำรอง
- คดี การตั้งค่า และเกมที่เล่นค้างอยู่ เก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น **ไม่มีการส่งออกเครือข่าย** ปุ่ม "ล้างข้อมูลทั้งหมด" อยู่ในหน้าตั้งค่า
- ถ้าเบราว์เซอร์ปิดการเก็บข้อมูล (เช่น โหมดส่วนตัวบางแบบ) จะมีแถบแจ้งเตือนและเกมยังเล่นได้ตามปกติ แต่ไม่บันทึก
- **สำรอง**: ใช้ "สำรองทั้งหมด"/"ส่งออก JSON" เก็บไฟล์ไว้ในแฟลชไดรฟ์/ไดรฟ์ของโรงเรียน (ข้อมูลหายถ้าล้างเบราว์เซอร์หรือเปลี่ยนเครื่อง) · รูปที่แนบถูกย่อ (ด้านยาวไม่เกิน 560 px) และจำกัดไฟล์ละ 4 MB แต่ละภาพใช้พื้นที่ราว 50–200 KB หน้าจัดการเนื้อหาแสดงพื้นที่ที่ใช้อยู่

## อัปโหลดขึ้นเว็บ (Static)
อัปโหลดทั้งโฟลเดอร์ `detective-mystery-zw1a/` ไปไว้ใต้โดเมน Static (เช่น Cloudflare Pages) ให้ได้ URL รูปแบบ `https://games.kruaorry.com/detective-mystery-zw1a/`
ไม่ต้อง build ไม่มี dependency · ไม่ต้องแก้หน้ารากหรือการตั้งค่าเว็บหลัก (เกมนี้ไม่มีดัชนีรวมเกม) · **ชื่อโฟลเดอร์ที่มีรหัสสุ่มไม่ใช่ระบบป้องกันการเข้าถึง** ใครมีลิงก์ก็เปิดได้ (หน้าเกมมี `noindex` เพื่อไม่ให้ค้นหาเจอ)

## การทดสอบที่ทำจริง (Chromium + Playwright, เซิร์ฟเวอร์ localhost)
ผ่านทั้งหมดในรอบล่าสุด: เปิดเกม · ทดลองเล่นครบ (8 จุด + เส้นเชื่อม + สรุปคดีผิดแล้วแก้ใหม่ + รายงาน + เฉลยทีละขั้น) · สร้างคดีใหม่ผ่านฟอร์ม (5 หลักฐาน) แล้วเล่นจบ · แก้/ลบ/ทำสำเนา · ตัวตรวจจับเฉลยหลุดและหลักฐานขัดเฉลย · export → ลบ → import → export ได้ JSON เหมือนเดิมทุกฟิลด์ · แข่ง 2 ทีมและ 4 ทีม (สลับตาถูกต้อง) · ปิดจับเวลา / เปิดจับเวลา (หมดเวลาไม่หักคะแนน, ต่อเวลา) · พัก/เล่นต่อด้วยปุ่ม Space (เวลาหยุดจริง) · ย้อนคำสั่ง (Undo) · แก้คะแนนโดยครู + ตารางที่มาคะแนน · เล่นต่อหลังออกจากเกม/รีโหลด · พิมพ์/PDF หน้ารายงาน · จอ 320px (ไม่ล้นแนวนอน ปุ่มสูง ≥ 44px) และ 1280×720 / 1920×1080 · ตัดอินเทอร์เน็ตแล้วเล่นต่อ (ไม่มี request ใหม่) · ทุก request เป็น same-origin · ไม่มี JavaScript error · เบราว์เซอร์บล็อก localStorage แล้วยังเล่นได้ · CSV ป้องกัน formula injection · ไฟล์ JSON ผิดรูปแบบ/schemaVersion ใหม่กว่าถูกปฏิเสธด้วยข้อความไทย · HTML ที่พิมพ์ในข้อมูลครูไม่ถูกแทรกเป็นโค้ด

## ข้อจำกัดที่ยังมี
- ทดสอบอัตโนมัติด้วย Chromium เท่านั้น (Firefox/Safari/แท็บเล็ตจริงและโปรเจกเตอร์ยังไม่ได้ทดสอบ), ไม่ได้วัด fps จริงบนเครื่องรุ่นเก่า
- เสียง (Web Audio) และเพลงบรรยากาศไม่ได้ฟังจริงในการทดสอบ ตรวจเฉพาะว่าไม่มีข้อผิดพลาด; การพิมพ์ตรวจด้วยการสร้าง PDF
- นำเข้า CSV รองรับเฉพาะคำถามปรนัย 4 ตัวเลือก และสร้างหลักฐานร่างที่ครูต้องเติมข้อมูล
- ตรวจ "เฉลยหลุด" เป็นการเทียบข้อความเดียวกันตรง ๆ เท่านั้น (ไม่ตรวจความหมายใกล้เคียง) และตรวจ "หลักฐานขัดเฉลย" จากช่อง "หลักฐานนี้ชี้ไปทางเลือกใด" ที่ครูระบุ — ครูควรอ่านคดีทั้งเรื่องอีกครั้งก่อนใช้จริง
- พื้นที่เก็บข้อมูลของเบราว์เซอร์จำกัด (ราว 5 MB) การแนบรูปจำนวนมากอาจเต็ม — เกมจะแจ้งเตือนและยังเล่นได้
